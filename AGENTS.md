# Bread Butter Bytes

- Public repo: <https://github.com/BenGOsborn/breadbutterbytes>.
- This repo owns website code and article content. Eleventy is the chosen tool.
  The site is still a shell.
- Before work, read the private [index](../breadbutterstrategy/AGENTS.md) and its
  contributing rules. Load other topics only when needed.
- Private repo: <https://github.com/BenGOsborn/breadbutterstrategy>.
  Look for `../breadbutterstrategy` from this repo's root. If missing, cloning it
  there is allowed. Check its remote; never overwrite an existing folder.
  If access fails, report the missing context.
- Keep private rules and plans out of public files and build output.
  The site build must work without the private repo.
- Normally use a feature branch. Do not touch main unless the owner explicitly
  allows it. The current agent-context setup is allowed on main.
- Never stage, commit, or push unless explicitly asked for that operation.
  Leave edits unstaged and preserve the owner's existing staged work.
- Keep things simple. Add implementation docs only when needed now.
  Do not add placeholder docs for future features.
